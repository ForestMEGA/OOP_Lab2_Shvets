## Practic work 2

Проект є модифікацією першої лабораторної роботи. Програму було переписано з використанням принципів інкапсуляції, властивостей та обробки винятків.

 Структура проекту
* Drone.cs — клас, який описує дрон (модель, швидкість, батарея).
* DroneManager.cs — клас, який зберігає список дронів та керує ними (додавання, пошук, видалення).
* Program.cs — консольне меню для взаємодії з користувачем.

## Що конкретно було зроблено в Lab-2:

1. Всі поля класу Drone (model, maxSpeed, batteryCapacity, currentBatteryLevel) переведено у модифікатор доступу private.
2. Для взаємодії з полями додано публічні властивості. У секціях set реалізовано перевірки: якщо модель порожня або швидкість і батарея менше або дорівнюють 0, генерується ArgumentException.
3. Додано автовластивість Status із значенням за замовчуванням "Готовий до вильоту".
4. Створено обчислювальну властивість RemainingEnergy, яка автоматично розраховує залишок енергії в мАг на основі ємності та відсотка заряду.
5. Для властивості Id встановлено обмежений рівень доступу private set, що забороняє змінювати ідентифікатор дрона за межами класу.
6. Логіку польоту приховано за допомогою приватних методів CheckSystem та CalculateTime, які викликаються всередині публічного методу StartFlight.
7. Встановлення значень в Program.cs реалізовано через властивості. Можливі помилки некоректного введення даних від користувача тепер обробляються за допомогою блоків try-catch.

## Запуск програми
Для запуску проекту необхідно відкрити всі три файли в середовищі Visual Studio або VS Code в межах одного проекту та виконати компіляцію.
